## 5. 설계 결정과 대안

### 선택

공용 classifier prompt에 다섯 route 의미, narrowest-row 선택과 binding coverage exclusion
규칙을 compact하게 넣는다.

### 이유

DeepSeek와 Upstage의 closed wire·server parser를 공유하면서 모델별 prompt drift 없이 의미
결정만 보강한다. 호출 수·비용·저장·공개 계약을 늘리지 않는다.

### 고려했지만 선택하지 않은 대안

- DeepSeek 전용 few-shot: 단기 정확도는 높일 수 있지만 provider drift와 과적합 위험.
- two-stage LLM route/topic: 호출·비용·latency와 실패 표면이 증가.
- 결정론 키워드 확장: fixture 과적합이며 자연어 일반화가 낮다.
