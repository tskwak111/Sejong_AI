### 선택

- 기존 ACTIVE 20 local DB를 보존하고 reset/seed/regression을 다시 실행하지 않는다.

### 이유

- feature worktree에는 primary ignored `.env`가 없고, 검증된 local DB는 이미 ACTIVE 20이다.

- 곧바로 AI mode 활성화: 기본 실행 원인 분리를 어렵게 하므로 첫 smoke 뒤 선택.
