- PII/policy/high-confidence는 deterministic, safe ambiguous-only Upstage.
- text-free signed context v2, ACTIVE/OFFICIAL-only retrieval, server-owned sources.
- civic scope-gap queue와 기존 grounding failure candidate flow를 분리.
- public admin/provider disabled, configured target이 없으면 non-execution.
### 이유

- “모르면 지어내지 않고, 알면 끝까지 안내한다”를 자연스러운 대화와 운영 개선에도 유지한다.
