## 5. 설계 결정과 대안

### 선택

server-owned category-aware FOLLOWUP을 선택한다. specific score와 explicit out-of-scope를
먼저 판정하고 남은 generic `증명서`만 CERT FOLLOWUP으로 보낸다. Web은 typed intent로
certificate prompt를 고른다.

### 이유

unsupported `졸업증명서`를 지원 범위로 오인하지 않고, 시민이 특정 증명서를 말하지 않았을
때 임의 KB를 선택하지 않으며, 다른 API consumer에도 같은 의미를 제공한다.

### 고려했지만 선택하지 않은 대안

- generic term을 weighted intent에 추가해 즉시 검색: 특정 KB 추측과 OOS 오분류 위험.
- Web-only 특례: server event/context 의미가 계속 UNKNOWN이고 표시 문자열 결합이 생김.
