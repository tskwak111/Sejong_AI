## 5. 설계 결정과 대안

### 선택

local interactive demo profile을 classifier 80, generator 100, combined 160으로 둔다.
요청당 최대 2 calls, 3초/8초, retry 0, concurrency 1과 process 내 counter reset 금지는 유지한다.
session 비용 stop line은 VAT 포함 USD 0.20이다.

### 이유

핵심·확장 UAT를 한 번의 process에서 실행할 수 있으면서 무제한 호출은 방지한다.

### 고려했지만 선택하지 않은 대안

- 20/30/40 유지: 일반 UAT에서 너무 빨리 소진된다.
- cap 제거: 비용·반복 요청 통제가 없다.
- production 사용자별 rate limit: 인증·운영 인프라가 없어 현재 P2다.
