## 3. 변경 상세

1. **질문 원문 URL 제거 (태성 리뷰 1, Critical)**
   - 신규 `src/lib/pending-question.ts`: `setPendingQuestion`/`consumePendingQuestion` — 모듈 스코프 변수만 사용, 스토리지·쿠키 미사용, consume은 1회성. 새 탭에서 열면 값이 없어 빈 대화로 시작(의도된 동작).
   - `src/app/page.tsx`를 server 컴포넌트로 축소하고 UI를 `src/app/home-screen.tsx`(client)로 분리. 홈 입력 submit과 추천 질문 칩 모두 `setPendingQuestion(q)` 후 `router.push("/chat")`/`href="/chat"` — 쿼리스트링 없음.
   - `src/app/chat/chat-screen.tsx`: `useSearchParams` 제거(→ Suspense 래퍼도 제거), mount 시 `consumePendingQuestion()` 1회 소비 후 자동 전송.
2. **모드 기본값 반전 + fixture 배너 (태성 리뷰 2)**
   - `chat/page.tsx`: `CHAT_UI_MODE === "fixture" ? "fixture" : "actual"` (미설정=actual). actual 연결 실패는 기존 값 없는 오류 카드("다시 시도")가 안전 화면 역할.
   - `admin/layout.tsx`: `ADMIN_UI_MODE === "fixture" ? "fixture" : "actual"` (미설정=actual). 실패는 화면별 오류 상태·재시도 UI.
   - 신규 `components/common/FixtureNotice.tsx`: "시연용 샘플 — 공식 데이터 아님" — warning(앰버) 토큰, 공지 배너(NoticeBanner, primary 톤)와 시각 구분.
   - 노출 위치: 홈(`home-screen.tsx`), 대화(`chat-screen.tsx`), 이음센터 전 화면 + 관문(`AdminShell.tsx` 본체·login 분기). 각 모드가 fixture일 때만.
   - `.env.example`: 기본값·배너 동작 주석 갱신 (`CHAT_UI_MODE=actual`, `ADMIN_UI_MODE=actual`).
3. **PERSONAL_LOOKUP 원문 미저장 (태성 리뷰 3)**
   - `lib/demo-fixtures.ts` `enqueueFailure(maskedQuestion: string | null, …)` — 데모 #4 경로는 `null`로 적재. 사전 시드된 데모 행(`DEMO_PERSONAL_FAILURE_ID`, 데모 #5용)은 유지.
   - 알려진 임시 상태: `masked_question=null` + `text_purged_at=null` 조합은 계약 불변식(null ⇔ purge 기록, `invalid-failed-null-without-purge.json`)과 어긋난다. 당시 행 생성 여부 결정은 [역사적 감사 C1/⑥](../audits/FRONTEND_PR8_MISMATCH_REPORT.md)에 기록했다. 이후 D-059/D-068과 IMP-20260724-010이 "행 미생성"으로 확정·정리했다. fixture 인메모리 전용이라 이 중간 상태는 계약 검증 경로를 통과하지 않았다.
   - 부수 효과: 신규 적재 건이 실패 큐에서 "보관 기간 경과 (질문 텍스트 파기됨)"로 표기됨(기존 NULL 렌더링 재사용) — 팀 결정 전 임시 표기로 수용.
4. **피드백 문구 (태성 리뷰 4)**: `FeedbackButtons.tsx` "의견을 보내주셔서" → "의견을 선택해 주셔서" (전송 미구현 상태의 정확한 표현).
5. **테스트 갱신**: `page.test.tsx`(칩 href="/chat"+탭 메모리 소비, submit 경로, 배너 부재), `chat/page.test.tsx`(기본 actual·fixture 배너), `admin/layout.test.tsx`(기본 actual, fixture 명시+배너), `chat-screen.test.tsx`(탭 메모리 자동 전송·1회성 소비·URL 무잔존), `admin-flow.test.tsx`(PERSONAL_LOOKUP masked_question null).
