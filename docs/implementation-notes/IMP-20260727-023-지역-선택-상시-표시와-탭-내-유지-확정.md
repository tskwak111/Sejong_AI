## 5. 설계 결정과 대안

### 선택

입력창 위에 selector를 항상 compact하게 표시한다. 새 대화는 메시지, idempotency 실패 draft,
context token과 topic state를 초기화하지만 selected region은 같은 탭 React memory에 유지한다.
새로고침·새 탭·브라우저 종료에서는 초기화한다.

### 이유

사용자가 현재 지역을 항상 확인·변경할 수 있고, raw transcript나 사용자 프로필을 저장하지
않으면서 반복 질문의 마찰을 줄인다.

### 고려했지만 선택하지 않은 대안

- 첫 화면 전용: 질문 뒤 변경 진입점이 약하다.
- 기관이 필요할 때만 질문: 지역 관련 발견이 늦고 반복 입력이 생긴다.
- browser storage 영구 저장: 현재 개인정보·프로필 비저장 경계를 넓혀 제외한다.
