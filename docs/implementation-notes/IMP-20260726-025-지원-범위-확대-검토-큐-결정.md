### 선택

`CIVIC_SCOPE_GAP`은 existing failure/candidate와 별도 review queue로 취급한다. masked text만
30일 보관하고 자동 KB/ACTIVE 전환을 금지한다.

### 이유

수요 분석 목적과 KB 품질 개선 목적을 분리하고, current supported-intent invariant를 약화하지
않는다.

- current failed queue 재사용: 잘못된 ACTIVE 승격 가능성과 DB invariant 위반으로 거절.
- current OUT_OF_SCOPE에 text만 저장: 숨은 개인정보 정책 파괴로 거절.
- 자동 새 category 생성: PM 범위·공식 데이터 승인 우회로 거절.
