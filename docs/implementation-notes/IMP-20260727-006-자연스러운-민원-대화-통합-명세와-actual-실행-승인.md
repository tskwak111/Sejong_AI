## 5. 설계 결정과 대안

### 선택

privacy-first hybrid pipeline, context v2, separate scope-gap queue, existing human approval flow의
세 수직 slice와 마지막 actual/public integration을 선택했다.

### 이유

사용자 동작을 자연스럽게 만들면서도 모델 권한을 분류·summary 제안으로 제한하고, 질문 원문
미저장·공식 근거·별도 승인 원칙을 유지할 수 있다.

### 고려했지만 선택하지 않은 대안

- 모든 질문 LLM 분류: 개인정보·비용·장애 표면 때문에 기각.
- deterministic term table만 확장: 새 표현 recall을 해결하지 못해 기각.
- broad public 승인으로 admin과 real-user LLM까지 즉시 공개: 인증·법무 gate가 없어 기각.
