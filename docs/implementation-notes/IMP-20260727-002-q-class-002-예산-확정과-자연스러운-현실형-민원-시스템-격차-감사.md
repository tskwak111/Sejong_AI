## 5. 설계 결정과 대안

### 선택

Q-CLASS-002=A:

- classifier: 요청당 1 attempt, 3초, retry 0, 입력 1,024자, 출력 128 token, sub-cap 20
- grounded generation: 기존 8초, 1 attempt, sub-cap 30
- combined process cap 40
- local synthetic run cost stop line: VAT 포함 USD 0.05
- hidden retry/counter reset 금지

자연스러운 대화는 모든 raw history를 LLM에 보내는 방식이 아니라 PII 오탐 교정, closed route
hybrid 분류와 text-free structured context v2로 개선하도록 권고했다.

### 이유

provider가 분류를 제안하더라도 개인정보·정책·검색·출처·저장 권한을 서버에 남긴다. context
v2는 topic/pending slot을 유지하면서 기존 원문 미저장 원칙을 지킬 수 있다.

### 고려했지만 선택하지 않은 대안

- term table만 확장: 새 표현마다 회귀하고 자연어 recall 한계가 지속된다.
- 모든 질문과 전체 대화 history를 LLM에 전송: 개인정보·비용·오분류 표면이 커진다.
- KB가 없는 분야도 LLM이 자유 답변: 공식 근거 원칙과 충돌한다.
- 실제 신청/상태조회를 현재 slice에 혼합: 기관 연계·인증·transaction 요구를 숨기므로
  Q-PROD-REAL-001 전에는 제외한다.
