## 5. 설계 결정과 대안

### 선택

현재 수준을 local/private MVP와 발표 데모에는 사용한다. DeepSeek는 최종 행정 사실이나 출처를
만들지 않고 질문 분류 보조만 담당하며, 서버 strict parser·ACTIVE/OFFICIAL KB·결정론적 fallback을
계속 최종 권위로 둔다.

### 이유

연결·HTTP·JSON·server acceptance는 9/9이고 비용과 개인정보 경계도 통과했다. 정확도는 완벽하지
않지만 provider 대상 고정 9건 중 8건이 일치했다. 공개 서비스가 아닌 MVP에서는 이 정도 품질을
사용자에게 “AI 보조 분류 + 근거 없으면 폴백”으로 설명하면 합리적이다.

### 고려했지만 선택하지 않은 대안

- `9/9`가 될 때까지 즉시 반복 actual: one-shot 증거를 위반하고 fixed set 과적합 위험이 있어
  선택하지 않았다.
- DeepSeek 결과를 그대로 시민 답변으로 사용: 공식 사실·출처 authority를 모델에 넘기므로
  선택하지 않았다.
- AI를 전부 끄기: 데모 안정성은 높지만 자연어 변형 대응을 보여주기 어려워 local MVP 선택지로만
  남긴다.
